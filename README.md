**my-agent-demo**

## Description

A demo project showcasing an AI-powered documentation agent that can read, update, and maintain project documentation automatically. This repository serves as an example of how to integrate AI tools into the software development workflow to keep documentation up-to-date and consistent.

## Features

- **Automated Documentation Generation**: Generate and update README, API docs, and other markdown files.
- **AI-Powered Code Insight**: Uses language models to understand code structure and suggest documentation improvements.
- **Branch Management**: Creates and switches branches for documentation updates.
- **Pull Request Automation**: Opens PRs with formatted descriptions and issue linking.
- **Extensible Architecture**: Easily add new documentation generators or integrate with CI pipelines.

## Usage

Run the documentation agent from the command line:

```bash
python -m agent.main --task update-readme
```

The agent will:
1. Scan the repository for existing documentation.
2. Generate an updated README based on code changes.
3. Create a new branch, commit the changes, and open a pull request.

You can also invoke specific tasks, for example:

```bash
python -m agent.main --task generate-api-docs
```
